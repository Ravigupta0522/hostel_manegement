# PROJECT TASKS

---

## Phase 1 — Project Setup

### Objective

Set up the initial Flutter project structure and development foundation according to the defined architecture and design system.

### Tasks

- Create the Flutter project.
- Configure the Dart and Flutter project environment.
- Set up the project folder structure.
- Configure the `core` directory.
- Configure the `data` directory.
- Configure the `modules` directory.
- Configure the `routes` directory.
- Configure `main.dart` and `app.dart`.
- Set up the GetX architecture.
- Set up GetX Bindings.
- Configure the application theme.
- Configure the application colors.
- Configure typography.
- Create reusable UI components according to the Design System.
- Configure responsive layout support for mobile, tablet, and desktop.
- Configure required project dependencies.
- Establish the basic View → Controller → Repository/Service → Data flow.

---

## Phase 2 — Authentication

### Objective

Implement the authentication module with a properly separated and structured authentication flow.

### Tasks

- Create the Authentication module.
- Create the authentication views.
- Create authentication controllers.
- Create authentication bindings.
- Create the Login screen.
- Create the Register screen.
- Create the Forgot Password screen.
- Create the OTP verification screen.
- Create the Reset Password screen.
- Create required authentication form fields.
- Add form validation.
- Add loading states.
- Add success and error states.
- Configure authentication navigation.
- Maintain proper separation between authentication UI, controller logic, and data/service logic.
- Ensure authentication screens are responsive across mobile, tablet, and desktop.

- Add appropriate error states.
